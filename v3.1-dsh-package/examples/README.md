# Examples

Two kinds of material live here.

## 1. A runnable fixture — `bonded-apartment-intake/`

A realistic intake brief for a 75-room bonded apartment conversion, written so you can drop it into a
session and watch the loop work. It is deliberately incomplete in the way real briefs are: no cost
structure, no demand-side evidence, no competitor occupancy, a payback figure whose basis is not shown.

Every number is either given with a stated source or explicitly marked as an assumption, so the skill
has something to grade. Ask for `AUDIT`, `RED_TEAM` or `GROWTH_DIAGNOSIS` and compare what you get
against the "what a good run should produce" section at the end of the brief.

## 2. A case study — `case-study-bonded-apartment.md`

The anonymised record of three independent runs against a real engagement of the same shape, including
the findings they produced, the arithmetic behind each one, and — this is the point — **the defects
those runs exposed in this skill and what was changed as a result.**

Client documents are not included. Figures are the ones that appeared in the arithmetic; names,
locations and entities are removed. Read it if you want to judge whether the method finds anything a
competent analyst would not.
