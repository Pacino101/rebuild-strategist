## 迭代路线

### V3.2.1 — 评测可复现
- 运行四个固定基准案例；
- 进行普通提示词、单 Skill、实际多 Agent 三组对照；
- 至少两名评审盲评；
- 发布原始评分和失败样本，不只公布平均分。

### V3.3 — 项目记忆与决策回退
- 设计项目状态版本与变更日志；
- 将关键假设和决策依赖关系连接起来；
- 证据变化时自动列出受影响的决策节点；
- 引入用户确认与人工审批。

### V3.4 — Harness 原生执行层
- 根据用户实际安装的 Harness 版本与能力，开发独立适配器；
- 真实执行子 Agent 调度、任务状态、超时和失败重试；
- 添加集成测试和安装说明；
- 任何能力只有通过运行测试后才能标记为“已实现”。

### V4 — 可公开验证的产品
- 公开基准结果、方法局限与复现脚本；
- 增加行业案例，但严格区分合成数据和真实客户数据；
- 形成稳定版本策略、贡献指南、许可证和安全政策。
